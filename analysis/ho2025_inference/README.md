# Ho2025 → learned-LIF connectivity inference: results & analysis

Self-contained, reproducible bundle. Applies this repo's spike-only learned-LIF
connectivity inference (+ CCG baseline) to the **Ho et al. 2025** cortical network
(ModelDB **2018263**, 4-AP / gK-downmodulation seizure model), and analyses where
inference succeeds and fails by neuron population and connection class.

Everything here regenerates from the committed data in `inputs/` — **no rerun of the
multi-hour inference is needed** to reproduce the numbers or figures.

## Conditions

Two 900 s simulations of the same 303-cell network (E2 = 65 L2/3 pyramidal,
E5 = 206 L5 pyramidal, I2 = 32 fast-spiking interneurons), differing only in the
potassium-conductance knob:

| condition | knob | regime |
|-----------|------|--------|
| **normal** | control gK | balanced E/I, sparse-ish bursting |
| **mauve**  | reduced FS gK (magenta preset) | disinhibited, uniformly hypersynchronous |

Ho2025 output was exported to a flat `.npz` (`export_npz.py`, in the Ho2025 repo)
and converted to this repo's session format by **`to_session.py`** (included here
for reference). The learned-LIF model was then run via `inference/adapter.py`.

## Headline results

| metric | normal | mauve |
|--------|--------|-------|
| learned-LIF AUC | **0.663** | **0.759** |
| CCG baseline AUC | 0.554 | 0.666 |
| AP / F1 | 0.415 / 0.398 | 0.582 / 0.544 |
| FDR | 0.674 | 0.435 |
| TP / FP / FN | 3084 / 6375 / 2947 | 3748 / 2891 / 3401 |
| **inhibitory-edge AUC** | **0.861** | **0.533** |
| **excitatory-edge AUC** | 0.786 | **0.845** |
| firing rate E2 / E5 / I2 (Hz) | 1.55 / 1.55 / 6.63 | 2.16 / 2.16 / 7.34 |

*(CCG AUCs are from the inference run logs, not recomputed here; everything else is
regenerated by `analyze.py`.)*

### Key finding
In **normal**, inhibitory-origin edges are the *easiest* to recover (I→E recall
0.75, I→I 0.70). In **mauve** it inverts: excitatory E→E improves (recall 0.64) but
every edge touching an FS (I2) neuron collapses — **I→E recall 0.006 (4 of 702 real
edges)**. Firing rates show this is **not** depolarization block: I2 fires *more* in
mauve (6.63→7.34 Hz) and no cell goes silent. Instead, excitatory-cell rate variance
collapses (E5 sd 0.12→0.01 Hz — hypersynchrony), so individual inhibitory synapses
lose the detectable "pause" signature inference relies on. It is a **spike-timing
effect, not a rate effect** (see `plot_rate_vs_outcome.py`: high-rate I2 cells are
*not* over-predicted; their predicted-edge count drops 104→12 despite higher rate).

## Reproduce

```bash
# needs: numpy, scikit-learn (analyze); matplotlib (plots)
python analyze.py               # inputs/ -> results/{results.json, *.csv}  (recomputes all numbers)
python plot_firing_rates.py     # results/per_neuron_outcomes.csv -> results/ho_firing_rates.png
python plot_rate_vs_outcome.py  # results/per_neuron_outcomes.csv -> results/ho_rate_vs_outcome.png
```

## Layout

```
analyze.py                 recompute all stats from inputs/ -> results/ (numpy + sklearn)
plot_firing_rates.py       firing rate by group + pre/post rate by class
plot_rate_vs_outcome.py    per-neuron rate vs TP/FP (pre & post) and vs predicted edges
to_session.py              (reference) Ho2025 flat-npz -> session-format converter
inputs/
  connectivity_<cond>.npz  learned signed weight matrix [post,pre], neighbor_indices, threshold
  network_<cond>.npz        ground-truth topology: connections, positions, cluster/population labels
  recording_<cond>.npz      spike trains (900 s) + resampled raster
results/
  results.json              overall + directional AUCs, per-class + per-population confusion, rates
  results_summary.csv       one row per condition
  confusion_by_class.csv    TP/FP/FN by E/I class and by population pair
  per_neuron_outcomes.csv   per-neuron rate, population, TP/FP (pre & post), predicted-out edges
  ho_firing_rates.png, ho_rate_vs_outcome.png
```

## Definitions (match `inference/lif_inference/connectivity_metrics.py`)

Confusion is over the **candidate pairs** the model scored (K=100 spatial+temporal
presynaptic candidates per postsynaptic neuron), not all N². For post neuron `p` and
each `pre ∈ neighbor_indices[p]`: `score = |connectivity_matrix[p, pre]|`,
`predicted = score ≥ threshold`, `label = 1` iff `pre→p` is a real edge. Firing rate
= spike count / 900 s. "recall" is recall among candidates.

## Caveats
- Validation inside training was held-out event *windows* from the same recording
  (one 900 s recording per condition), not a held-out recording.
- `mauve`'s higher raw AUC partly reflects common-input inflation (its CCG baseline
  also rises to 0.666); the learned model's ~0.09–0.11 AUC margin over CCG is the
  part beyond correlation.
- The `seizure` (GKE 0.3) condition is **not** included — its export was a duplicate
  of mauve; a real one needs re-export from the Ho2025 repo.
