# Figures — dataset_noise7_random2

Which pipeline produced each figure, and at what operating point.

**Two kinds of result appear here.** *Label-free* means the detection threshold
came from a spike-jitter surrogate null with no access to ground truth; ground
truth is used only to score the result afterwards. *Oracle* means the threshold
was chosen using ground truth — an upper bound, not a deployable method. Only
`glm_scaling_vs_duration.png` is oracle.

Regenerate any figure with:

```bash
DATASET_SESSION=dataset_noise7_random2 DATASET_STATE=<state> python <script>
```


## normal  (scaling curves run to 200 recordings)

### `burst_gate_sensitivity.png`

**Generated by:** `analysis/burst_gate_sensitivity.py`

How the burst count and rate depend on the acceptance gate.

*Pipeline:* No inference. Same detector with the acceptance gate swept; the bracketing stage is held fixed.

### `burstwindows_p035_starts.png`

**Generated by:** `analysis/burst_windows_p035.py`

Burst start times across recordings, split into initialization-locked and spontaneous classes.

*Pipeline:* No inference. Burst detection only: participation > 0.35 of distinct neurons over a data-defined event window.

### `fdrdur10to200_calibration.png`

**Generated by:** `analysis/fdr_duration_200_worker.py + _combine.py`

Realized vs nominal FDR per duration; calibration error; and the realized-FDR heatmap over (target x duration).

*Pipeline:* Same label-free operating point, swept over 13 durations x 10 nominal targets. Nominal target 1.0 is excluded from the PLOTS (it admits every candidate pair by construction); the CSV and JSON keep it.

### `fdrdur10to200_performance.png`

**Generated by:** `analysis/fdr_duration_200_worker.py + _combine.py`

F1, recall, precision, realized FDR, TP and predicted-edge count vs duration, one curve per nominal target.

*Pipeline:* As above.

### `glm_distance_recovery.png`

**Generated by:** `analysis/glm_distance_recovery.py`

Distance-resolved recovery: (a) recall/precision vs inter-neuron distance, (b) within- vs between-cluster recall, (c) GLM score for true edges vs background, (d) edge-count density vs distance.

*Pipeline:* Reads glm_connectivity_sum4_5ms.npz produced by analysis/glm_fit_current.py -- the REVISED pipeline including the A1 typing fix. Earlier versions of this figure used a pre-fix file whose inhibitory layer was effectively empty (4 neurons typed, 8 edges).

### `glm_labelfree_scaling_vs_duration.png`

**Generated by:** `analysis/glm_labelfree_scaling.py`

Edge recovery vs recording duration, three layers (excitatory / inhibitory / all edges).

*Pipeline:* LABEL-FREE inference. Sparse lag-resolved ridge GLM (bin 5 ms, lags 1-6, l2=2.0), sum4 readout. Threshold from a spike-jitter null (+/-25 ms, 8 surrogates, seed 1) at target FDR 0.70 -- ground truth is used only to score, never to threshold. Inhibitory layer restricted to pairs whose presynaptic neuron is typed inhibitory by the RANK rule (infer_inhibitory typing='rank', fraction=0.25) -- the A1 fix.

### `glm_predicted_topology.png`

**Generated by:** `analysis/glm_predicted_topology.py`

Predicted vs true wiring, whole network: spatial map with every edge drawn (TP green, FP red, FN orange dotted) and the cluster-sorted adjacency matrix.

*Pipeline:* Reads glm_connectivity_sum4_5ms.npz from analysis/glm_fit_current.py (label-free sum4 @FDR 0.70, A1 typing fix). At 926 neurons individual neurons are not resolvable -- use the zoom figures for that.

### `glm_scaling_vs_duration.png`

**Generated by:** `analysis/glm_scaling.py`

ORACLE upper bounds vs duration: best achievable F1, and recall at a true 10% FDR.

*Pipeline:* Same GLM fit, but thresholds are chosen USING ground truth. Not a deployable result -- it is the ceiling the label-free curve is measured against. Excitatory layer only.

### `glm_topology_zoom_cluster06.png`

**Generated by:** `analysis/glm_topology_zoom.py`

The three largest clusters, one row each: spatial zoom with neurons labelled by global id, and the within-cluster adjacency submatrix.

*Pipeline:* Same npz and operating point as glm_predicted_topology.png; this is a crop of it, not a re-fit. Only WITHIN-cluster pairs appear, so the precision and recall printed per cluster are local, not the global P=0.87 / R=0.85. Inhibitory presynaptic ids are blue: the near-empty orange rows line up with them. Network-wide, 53 of the 54 neurons that lose their entire out-row are inhibitory (31.4% of inhibitory neurons vs 0.1% of excitatory), driven by the typing gate -- the 36 true inhibitory neurons the rank rule misses have recall 0 by construction.
